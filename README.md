# Angular Technical Test

This project is a technical test built with Angular.

## Getting Started

To get started with this project, you can use the `start.sh` script. This script will:

chmod +x start.sh

1.  Copy the `.env.example` file to `.env`.
2.  Install the dependencies using `bun install`.
3.  Start the application using `bun start`.

```bash
./start.sh
```
